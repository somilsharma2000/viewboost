# 05 — Unicorn Roadmap

The thesis in one line: **win India's verified-attention niche fast, then become the world's proof-of-attention infrastructure layer.**

---

## Phase 0 — Foundation (Now → Week 4)
**Goal: bulletproof the promise.**
- [ ] PageVisibility + fingerprint + IP filtering verified against headless scripts
- [ ] Server-side-only wallet credits; immutable ledger
- [ ] ₹25 UPI cashout with nightly batch payouts
- [ ] Retention heatmaps + post-watch micro-polls shipped (the research layer)
- [ ] Drip-feed delivery engine (24–72h pacing, ±15% duration variance)
- [ ] Positioning rewrite per the [pivot doc](07-positioning-pivot.md)

## Phase 1 — Launch (Month 1–3)
**Goal: liquidity, not vanity.**
- Targets: 100k users · 15k paid campaigns · ₹15L monthly gross · viewer DAU/MAU > 35%
- Play: launch-week stunts (Speedrun, Hacker Bounty, #InstantUPIProof), 50-campus ambassador program, Telegram admin network
- Guardrail: fraud reject rate published publicly; time-to-first-payout under 24h

## Phase 2 — Category creation (Month 4–9)
**Goal: own "viewer research," not "views."**
- Launch **ViewBoost Insights**: creator dashboard with retention heatmaps, drop-off analysis, demographic cuts, poll results — positioned as India's most affordable focus group for video
- Launch **ViewBoost for Business**: D2C brands buy verified attention on promo Reels + genuine feedback
- Vernacular expansion: Hindi, Tamil, Telugu, Bengali UI + creator targeting
- Mobile apps (Android-first; the viewer side is Android-heavy in Tier 2/3)

## Phase 3 — Infrastructure (Month 10–18)
**Goal: become the verification layer.**
- **Attention Verification API**: any platform can rent the engine (ed-tech attendance, dating-app profile views, ad-attention audits, market research panels)
- Enterprise research panel: agencies buy *surveyed* verified watch sessions — the pivot's endpoint
- Series A story: marketplace revenue (proven) + API/platform revenue (expanding TAM)

## Phase 4 — Scale (Month 18+)
**Goal: geography & category expansion.**
- Southeast Asia (Indonesia, Philippines, Vietnam — same watch-and-earn demand, same payout pain)
- Creator-side SaaS: retention analytics suite competing with VidIQ on data no one else has (real human attention data, not estimates)
- The Attention Exchange as a marketplace: verified attention priced dynamically by content category, duration, audience quality

## Unit economics target model

| Phase | Monthly gross | Primary driver | Gross margin |
| :--- | :--- | :--- | :--- |
| Launch (M3) | ₹15L | Creator packages | ~38% |
| Category (M9) | ₹80L–₹1.2Cr | Packages + Insights subscriptions + business campaigns | ~45% |
| Infrastructure (M18) | ₹3Cr+ | API licensing + enterprise research panels | ~55%+ |

**₹100Cr ARR** ≈ Phase 4: India packages plateau around ₹8–12Cr/mo; API + SEA expansion carries the rest.

## What kills this (and the insurance)
1. **YouTube crackdown** → insurance: the research/feedback pivot means the core value survives even if view delivery is restricted
2. **Payout trust collapse** (one mass non-payment event) → insurance: over-collateralized payout float, public ledger, human-review appeals
3. **Bot arms race** → insurance: continuous bounty program (the ₹50k bounty becomes recurring, not one-off)
4. **Regulatory shift on earning apps** → insurance: legal counsel on GST/TDS classification from day 1, conservative KYC tiers (see [compliance doc](06-compliance-india.md))
